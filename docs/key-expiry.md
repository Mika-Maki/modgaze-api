# MR Key Expire

在「本地密钥」或分组的「密钥」页，点击 MR 虚拟 Key 的编辑按钮，可编辑 **MR Expires at**。

- 输入的是浏览器本地时间，编辑框会提示实际时区；保存时转换成 UTC 绝对时间。
- 留空表示永不过期；已有 Key 默认保持永不过期，不会自动设置截止日期。
- 保存即热生效；每个新 API 请求都检查到期时间，到期返回 HTTP 401 authentication_error，不再调用上游。到期不会强制截断已经开始的 SSE 请求。
- 只作用于 MR 虚拟 Key；直通 API Key 没有该字段，管理接口也拒绝给直通 Key 设置 expiresAt。
- 普通改标签保留原截止时间；轮换 MR Key 继承原截止时间，避免意外延长有效期。
- MR Key 到期后自动从当前配置和 WebUI 列表删除，同时清理其元数据；后台每秒检查，启动时也清理已过期 Key。若这是分组最后一个 Key，则保留分组、模型和路由并禁用分组，不自动生成替代 Key；直通 Key 和其他未到期 Key 不受影响。
- 需要延期时请在到期前修改；到期已删除后需要新建 Key。删除前沿用系统自动备份，删除不是安全擦除历史备份。

到期元数据保存在分组 virtualKeyMeta 对应 Key 指纹条目的 expiresAt（ISO 8601 UTC 字符串；null 表示永不过期），随配置备份/恢复；不改变 Key 本身或上游凭据。
